Corrections

    Envoyer la requête à la main quand ChatGPT est déjà ouvert

    Copie la requête complète (texte + consignes de correction) sans ouvrir de nouvel onglet. Le texte est mémorisé comme référence de comparaison, exactement comme avec le bouton d'envoi.

    Mettre le texte au propre retirer le rouge, garder ou non les mots barrés

    Les deux actions transforment le texte coloré en texte simple, prêt pour un nouvel envoi. Elles se distinguent sur les mots barrés que ChatGPT propose de supprimer : la première les garde (c'est aussi ce que fait le bouton principal), la seconde les enlève tous d'un coup. Dans les deux cas, un mot barré que tu as toi-même effacé reste effacé.

    Revenir en arrière annuler ou repartir de zéro

    « Revenir au texte envoyé » restaure la version telle qu'elle était avant l'application de la correction. « Tout effacer » vide l'éditeur.

    Stocker le texte sur GitHub identifiants, envoi, récupération

    Le texte (avec ses mots en rouge), le texte envoyé à ChatGPT et la date sont enregistrés dans un fichier JSON du dépôt. Le jeton reste dans ce navigateur et n'est jamais écrit dans le dépôt : utilise un dépôt privé et un jeton limité à ce dépôt.

    « Envoyer à ChatGPT » ouvre ChatGPT avec la requête pré-remplie et allume en vert le bouton « Appliquer la correction » : c'est le rappel qu'une réponse est attendue. Ce bouton suit ensuite le cycle du travail : il reprend sa couleur normale et devient « Accepter les corrections » une fois le texte corrigé affiché, puis retrouve son libellé d'origine quand tu as accepté. Dans le texte, un mot en rouge a été corrigé, un mot en rouge gras est un ajout proposé par ChatGPT, un mot en rouge barré est une suppression proposée : accepter garde tout en texte simple, y compris les mots barrés que tu n'as pas effacés toi-même. Pour les retirer tous d'un coup, ouvre « Mettre le texte au propre ». Seul le texte brut part vers ChatGPT — le rouge n'est jamais envoyé.
